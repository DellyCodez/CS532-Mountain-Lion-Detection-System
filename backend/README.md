# Project Name: Mountain Lion Detection System

The Mountain Lion Detection System is a system consisting of sensors connected to a computer running the main program. It's purpose is to detect mountain lion presence by listening for calls, growls, grunts and roars from the surrounding environment. The system sends an alert to the user to confirm the detection, and logs entries for later use.

# Subfolder: backend
This folder consists of the project backend, containing the scripts for each backend component.
