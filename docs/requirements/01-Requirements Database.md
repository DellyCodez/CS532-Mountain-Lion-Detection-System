# MLDS Requirements Database

## Overview

This document contains the requirements database for the Mountain Lion Detection System. The database is maintained by the development team and provides a central repository for tracking and managing system requirements throughout development.
The requirements will be reviewed, maintained, and updated as requirements are clarified or changed.

## Implementation Status Definitions

- Implemented: reported to work in the current prototype; not equivalent to independently verified acceptance.
- Partially implemented: some functionality exists, but required behavior or integration is incomplete.
- Planned: designed or scoped, but the required behavior is not yet implemented.
- Blocked: fulfillment depends on unfinished database, sensor, or alarm integration, or another explicitly identified prerequisite.

Status assignments below incorporate the team update supplied by the Requirements Manager and the previously inspected code. They describe the current prototype, not the final product. Verification is tracked separately. NFR-01/NFR-02 remain Open for validation; their Blocked labels describe unfinished dependencies, not failed tests.
